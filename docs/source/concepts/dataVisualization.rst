
Data Visualization 
==================

There a many different data visualization types. Which type to use depends on the goal. First lets discuss data visualization philosophy.


Philosophy
----------

Data can be categorized by dimensionality: 0D (scalers), 1D (lines), 2D (planes), 3D (boxes), and ND where N is an integer. Visualization of ND data requires N+1 visualization dimensions to plot. For example, 1D data can be ploted as a line graph on the x-y (2D) plane, where y coresponds as the element value and x corresponds to the element index. Visualization dimensions are not just limited to spatial dimensions but can use different qualities, such as color, to represent a data dimension. For example The same 1D data can be plotted in one horizontal line, whose x coordinate represents the element index and color represents the element value. In this way, >3D data can be visualized in one plot. For example 5D data can use a scatter plot with 3 spatial dimensions, 1 color dimension, 1 opacity dimension, and one marker shape dimension.
