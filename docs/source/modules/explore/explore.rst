
explore
-------

This module provides a few interactive visualization platforms (IVPs) and a starting point for developing personalized IVPs. 

Dmanage IVPs
^^^^^^^^^^^^

A list of the different IVP flavors is here. Each IVP has their own documentation.

Community IVPs (Not Implemented)
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Differnt IVP flavors created by the community are found here. Finding the best IVP for your application is easy. The IVPs are characterized by their intended application, visualization type, and other...  

Developing IVPs
^^^^^^^^^^^^^^^

Create personalized IVPs by using the relevant base classes avaivailiable in the module. These base classes provide thread managment and the class structure to easily integrate with data objects. Share IVPs here following the template; the template offers standards to make your IVP integrate with the dmanage methodology and to make it easier to find and use.
